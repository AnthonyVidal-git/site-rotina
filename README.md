# Minha rotina

Site para organizar a rotina do dia: mostra o dia em uma faixa de 24 horas com a hora atual, separa as tarefas em manhã, tarde e noite e salva tudo no navegador (localStorage). As marcações de feito zeram a cada novo dia.

Feito com HTML, CSS e JavaScript puro.

## Ver online
https://anthonyvidal-git.github.io/site-rotina/

## Como abrir
Abra o `index.html` no navegador ou use a extensão Live Server no VS Code.
